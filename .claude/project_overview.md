# Lucky Compressor: project overview

JUCE 9 (CMake + Ninja, FetchContent) VST3 compressor that teaches you to hear compression. Sibling of Lucky Reverb (`../lucky-reverb`) and Lucky Reference (`../lucky-reference`). AGPLv3. The agreed v1 behaviour is in `docs/spec.md`; `prototype/index.html` is the browser prototype the layout came from (spec wins where they differ).

## Layout
- `Source/dsp/Modes.*`: `Mode` (Clean, FET, Opto, VCA), `Controls` (user values in real units), `DetectorSettings` (what runs). `modes::constrain` clamps/snaps per mode, `modes::resolve` adds knee and release shape. FET dial <-> ms helpers, `snapLog`, per-mode `defaults`.
- `Source/dsp/Compressor.*`: detector + soft-knee gain computer, one-pole attack/release in the GR (dB) domain. Two-stage release for Opto and VCA Auto: average of a fast follower (60/100 ms) and a slow one whose time grows with a memory of recent reduction; `getReleaseSeconds()` exposes it for the UI.
- `Source/dsp/LevelMatcher.*`: records the last 3 s of input (K-weighted energy + detector level, atomics). `predict(settings)` replays it through a fresh `Compressor` twice (warm-up pass, then measured) and returns `sqrt(Ein / sum(E*g^2))`, clamped 0 to +30 dB; nothing until 0.1 s of sound. Within 0.5 dB of a real render.
- `Source/dsp/CompressorEngine.*`: per sample: detector, records input for the matcher, make-up ramps (80 ms) to an atomic target set by `setMakeupTarget`, 20 ms crossfade for the `bypass` parameter, shown as Compare with uncompressed (bit-identical once faded, unless level match held the make-up down for peaks: then the uncompressed side gets `setUncompressedTarget`). Meter ring of 8192 128-sample entries (4 s even at 192 kHz; input peak, compressed peak before make-up, max GR) as atomics; test hits go into two slots under `hitLock`, always the one not playing (the audio thread only try-locks to pick up a request); GR, release, make-up and "hearing audio" as atomics.
- `Source/dsp/ExampleHit.*`: real snare from `Resources/TestSnare.wav` (embedded as `LuckyCompressorSamples`, parsed in plain C++, windowed-sinc resampled to the host rate and cached, normalised to −6 dBFS), preceded by 3 identical hits 1 s apart so Opto memory is realistic, run through a fresh `Compressor`. Window 600 ms in every mode.
- `Source/PluginProcessor.*`: APVTS params `mode, threshold, ratio, attack, release, autoRelease, bypass, match, mix, mixMode, blend` (global, not per mode; `getBlend()` turns Mix/Blend into a `lucky::Blend {dry, wet}` used by the engine, level match, Lab and test snare) (real units, log ranges). `switchMode` saves the current controls for the old mode and loads the new mode's (memory saved in state as `ModeMemory` children). Host-automated mode changes don't swap memory. A low-priority `juce::Thread` (the processor itself) checks every 15 ms and calls `updateLevelMatch()` at most every `matchIntervalSeconds` (50 ms), only while Level Match is on: it re-predicts when the detector settings change, or per 0.25 s of new sound until the history is full; offline renders call it from `processBlock`, at most once per 50 ms of audio. `example_hit::makeHit` decodes the snare once and caches it per rate (the Lab draws at 48 kHz, S plays at the host rate).
- `Source/PluginEditor.*`: `LuckyCompressorView` (900x600, scaled by `LuckyCompressorEditor`, a `lucky::ScaledEditor`). Top bar (ripple logo in the mode colour, mode tabs with colour dots, ••• menu: version, Window size, Compare with uncompressed (C), Show mode info, Show Lab, Ask before showing GR). tips (one line per mode, `tips::mode`, under the top bar; the mode tabs have no tooltips), `LiveView` | `HitView` (the Lab), strip of six `Knob`s (Threshold, Ratio, Attack, Release, Colour, and the output knob under `lucky::LabelTabs` MIX | BLEND, whose spec swaps with the mode); the Level match `SmallSwitch` sits in the live view's header; compare with uncompressed via C, the ••• menu or the `lucky::KeyHintButton` at the right of the tip line; while comparing `accent()` is grey everywhere and a `lucky::ToggleNotice` sits over the live view (picking a mode turns it off; S plays the test snare; Space is left to the host). A 30 Hz timer `sync()`s knobs from parameters; knob specs per mode are built in `PluginEditor.cpp` (`amountSpec`, `ratioSpec`, `attackSpec`, `releaseSpec`) on shared scales (`attackScale`, `releaseScale`, `ratioScale`) with a usable band per mode.
- `Source/ui/`: `LiveView` ("YOUR SOUND"; envelopes binned by meter index, VBlank repaint, eye toggle reveals the GR readout, remembered in `showGainReduction`; turning it on first asks via `RevealPrompt` in a `juce::CallOutBox` unless `askBeforeShowingGainReduction` is off (••• menu); THRESHOLD chip), `HitView` ("Lab": real waveform of the test snare on a time grid; ⓘ `InfoDot`; ▶ TEST SNARE button and S call `LuckyCompressorProcessor::playTestHit`, which renders it with `example_hit::renderHit` (host rate, matched, ≤ −1 dBFS) and hands it to `CompressorEngine::playTestHit` (two slots, added to the output on its own path)), `WaveformDrawing.h` (shared threshold/GR drawing), `Tips` (copy), `ModeColours.h` (mode colours, `format::ratio`).
- Shared pieces come from `../lucky-labs` (`lucky_ui`: theme, format, look and feel, `Knob`, `SmallSwitch`, the ripple logo, `Settings`, `ScaledEditor`, key hints; `lucky_dsp`: `KWeighting`), wired in by `cmake/LuckyLabs.cmake`. Follow `../lucky-labs/docs/conventions.md` and read `../lucky-labs/docs/lessons.md` first.
- `Tests/`: `LuckyCompressorTests` (DSP, category "Lucky Compressor"), `LuckyCompressorProcessorTests` (links the plugin: defaults, mode memory, state, comparing, peak ceiling). `TestSignals.h` has the drum loop.
- `tools/Snapshot.cpp`: renders the editor to PNG after playing the drum loop through it.

## Notes
- Needs `../lucky-labs` checked out beside it (`LUCKY_LABS_DIR`).
- Configure with `-DFETCHCONTENT_SOURCE_DIR_JUCE=../lucky-reverb/build/_deps/juce-src` to reuse the JUCE checkout.
- The VST3 isn't installed unless `LUCKY_COMPRESSOR_INSTALL_AFTER_BUILD=ON`.
- `Source/dsp/Colour.*`: per-mode tone on the wet signal (envelope-normalised x²/x³ waveshaper with DC blocker; Opto high/low-pass), voiced from published hardware figures in docs/colour-sources.md (never from plugin output). `tools/Measure.cpp` (`LuckyCompressorMeasure`): headless measuring host for Lucky Compressor, or hardware via `--hardware <device> <out> <in>` (aligned with a click); only measure third-party plugins whose licence allows it. Only our own measurements are committed (`measurements/`).
- Behringer 676: measured (`measurements/676/`, `docs/676-comparison.md`); FET's compressing harmonics come from it. Still to measure: release at dial 7 (the 676 measured 223 ms, the manual says 50 ms), a Ratio 4 curve, attack times, absolute dBu levels.
- Release: v1.0.0 prepared (VST3 + AU, `packaging/`, `.github/workflows/`, promo page `docs/index.html`); CI checks out `tomdmaguire/lucky-labs`, which must be public. `tools/Benchmark.cpp` (`LuckyCompressorBench`) measures CPU.
- Not done yet: tip copy pass, serial compression (mock-up in `prototype/chain.html`).
