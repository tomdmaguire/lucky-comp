# Resources

## TestSnare.wav

The Lab's test snare: 0.95 s, mono, 48 kHz, 24-bit.

- Source: "kensnare1" by spacemanfan on freesound (sound 19785), CC0 1.0:
  https://freesound.org/people/spacemanfan/sounds/19785/. An uncompressed DW 13" snare, top and bottom mics.
- Changes: a small room added with Lucky Reverb (dry untouched, width mono), a 0.4 ms fade-in over the pre-roll
  and a 10 ms fade-out. Lucky Compressor scales it to −6 dBFS when it loads.

CC0 needs no credit; it's given anyway.
